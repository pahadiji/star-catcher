Ask Claude about every Claude repo

The Star Catcher MCP server lets Claude search all 3000 repos on this site: find a skill or MCP server for a job, see what is trending, read verified picks. It is one small file with no dependencies (Node 18+), and it only reads this site's public data.

Claude Code

curl -fsSL https://pahadiji.github.io/star-catcher/mcp/server.mjs -o ~/.star-catcher-mcp.mjs
claude mcp add star-catcher -- node ~/.star-catcher-mcp.mjs

Claude Desktop

Download server.mjs, then add this to claude_desktop_config.json:

{"mcpServers": {"star-catcher": {"command": "node", "args": ["/path/to/server.mjs"]}}}

Tools

  • search_repos

    Find repos by keyword, optionally in one category.

  • trending

    Fastest-growing repos this week.

  • repo_info

    Details for one repo, with its Star Catcher page.

  • verified_picks

    New repos approved by the senior agents.

  • list_topics

    Popular topics and how many repos each has.
