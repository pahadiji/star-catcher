a4agent

by eogee

a4agent（0.4.0 起由 a4api 是「八端 AI 编程工具管理台 + 本地大模型推理控制台」：为 Claude Code、Codex、dsh（DeepSeek Harness）、ZCode、pi、Qoder、OpenCode 与 WorkBuddy 提供统一的技能管理与 MCP 管理，为 Claude Code 和 Codex 提供服务商一键切换，内置 llama.cpp 本地大模型推理服务，并把七端（除 WorkBuddy）的无头任务下发与手机 / 桌面通知提醒也做进了同一应用中。本文章为文档库入口，概述项目定位、功能全景、安装与快速开始，并给出全部功能文档的导航。
