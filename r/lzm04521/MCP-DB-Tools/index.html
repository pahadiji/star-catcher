MCP-DB-Tools

by lzm04521

为支持 MCP（Model Context Protocol）的 Agent（如 Claude Code、Codex）提供数据库只读访问能力的工具。基于 .NET 8 + 官方 ModelContextProtocol SDK，支持 SQL Server、MySQL、Oracle，内置 SQL 安全守卫、多环境配置、配置热重载、每环境并发限流、审计日志，以及本机 Admin UI 配置维护页面。
